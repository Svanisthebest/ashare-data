## 第五十六轮　前十大股东 / 前十大流通股东数据（用户提供）（2026-11-23）

**数据**：用户上传的 holders_clean / floatholders_clean 两张表（Tushare 口径，2000-01 至 2026-11-20，各约 320–340 万行）。实际内容是**全市场每只股票、每个报告期的前十大（流通）股东名单**，不是单一私募的持仓。数据属用户私有，不放进本公开仓库，只在本地研究。
- 本地没有 parquet 读取库，网络也关着，所以自己写了纯 Python 读取器（thrift 元数据 + snappy 解压 + 字典编码）。读出行数与数据说明完全一致。
- 公告滞后：报告期结束后中位 31 天公告，90% 分位 111 天。研究一律按**公告日之后**才使用，防止未来函数。
- 量化私募（按幻方、九坤、明汯、灵均、衍复、宽德等 40 个名字识别）在前十大流通股东中极少：共约 2000 条、888 只股票，2020 年以后才多起来。

**方向 A：股东变动事件 → 新的中线入场模型**
- 方法：每期名单公告后，与上一期对比；公告日之后第一个交易日开盘买入，持有 5 / 20 / 60 天；超额收益扣除同期全市场等权平均，再扣同月均值，跨月做 t 检验。
- 13 个事先定义的特征：量化私募新进、私募新进、私募≥2 家新进、社保新进、QFII 新进、北向新进或加仓、国家队新进、牛散≥3 人新进、公募≥2 家新进、公募家数减≥2、集中度升 >5 点、集中度降 >5 点、自然人家数增≥3。
- 只用 2016–21 挑，2022–26 验证。门槛：挑选段 |t|≥2.5，验证段同方向且 |t|≥2。
- 结果：39 组（13 特征 × 3 个持有期）**无一通过**。
  - 集中度升 >5 点在 20 / 60 天两段都为正（+1.56% t2.1 / +0.81% t1.0；+2.04% t2.3 / +4.34% t1.5），但不显著。
  - 量化私募新进：5 天 +1.86%（t1.9）→ −0.39%，不稳定。
- 结论：名单公布时信息早已反映在价格里，不能单独做入场模型。

**方向 B：股东结构作为现有短线候选的特征**
- 给每笔 B7 交易（去重后的独立交易）配上信号日之前已公告的最新一期名单。91% 能匹配上，信息距信号日中位 57 天。收益先减去同路线均值。
- 13 个特征：有量化私募、有私募、无公募、公募≥3 家、自然人≥6 人、自然人≤2 人、有社保、有北向、有国家队、集中度 >60%、集中度 <25%、上期集中度上升、有 QFII。
- 结果：**无一通过**（门槛：2016–21 p<0.01 且 2022–26 同方向 p<0.05）。
  - 最接近的是公募≥3 家：−2.32%（p 0.02）/ −0.99%（p 0.45）。
  - 量化私募样本只有 7 + 5 笔，无法判断。

**结论**：前十大股东数据对现有短线系统和新的中线入场模型都没有可用增量，不采用。代码与中间结果保存在本地 /home/claude/pf。

## 第五十七轮　幻方、九坤持仓股的共性（2026-11-23）

**数据**：前十大流通股东中，九坤 238 条、160 只股票；幻方 153 条、140 只股票。幻方全部在 2017-09 至 2021-06（之后不再出现）。九坤主要在 2020–21；2024–26 的 49 条里 48 条是北交所，不在研究和交易范围。两家持股中位只占流通股的 0.53%。剔除 ST 和北交所后，有效 309 条。

**共性**（在报告期末与同日全市场比较；流通股本由前十大流通股东表反推）

| 特征 | 九坤 | 幻方 |
|---|---|---|
| 上市天数中位 | 167（全市场约 2100） | 1346 |
| 上市 <1 年占比 | 92% | 20% |
| 板块 | 科创 68%、创业 20%、主板 13% | 主板 53%、创业 46% |
| 流通市值分位 | 4%（中位约 8.5 亿） | 21%（中位约 18 亿） |
| 20 日换手分位 | 84%（日均换手约 5.8%） | 96%（日均换手约 11.6%） |
| 20 日波动率分位 | 66% | 94% |
| 近 60 日有涨停占比 | 48% | 82%（中位 3 次，全市场均值约 0.7） |

- 九坤：几乎只出现在流通盘极小的次新股（尤其科创板）里。约 30% 是新股上市后的第一份报告，更像打新或次新股策略的结果，不是主动选股信号。
- 幻方：集中在正在被炒作、换手极高的小盘股，也就是我们情绪短线系统的同一个池子。

**公告后跟随**（公告次日开盘买；幻方对照组 = 同日换手前 10% 且市值后 40%，九坤对照组 = 同日次新股）
- 幻方 149 个事件：相对同类 1 天 +0.25%，5 天 +1.68%（事件级 t=2.4，但胜率只有 46%，同日事件扎堆、t 值高估），20 天 −0.01%，60 天 +1.97%（t=0.7）。只有 2017–21 一段，无法做两段验证。
- 九坤 151 个事件：各持有期都不显著（t 在 −0.3 到 1.0 之间）。
- 同类股本身跑输：高换手小盘股 60 天跑输全市场 3.8%，次新股跑输 2.8%。量化私募在这里的收益来自高频交易，日线无法复制。

**幻方式特征用于现有候选**（流通股本取公告次日起可用的值；收益减去同路线均值）

| 特征 | 2016–21 | 2022–26 |
|---|---|---|
| 换手前 10% | 282 笔 +0.72%（p 0.42） | 367 笔 +0.74%（p 0.37） |
| 市值后 30% | 168 笔 +0.02%（p 0.98） | 155 笔 +1.30%（p 0.13） |
| 换手前 10% 且市值后 40% | 144 笔 +0.29%（p 0.82） | 127 笔 +1.99%（p 0.08） |
| 近 60 日涨停≥3 次 | 502 笔 +0.05%（p 0.96） | 706 笔 +0.75%（p 0.30） |

方向都为正，但没有一个显著，不能用作规则。另外，我们的候选里本来就有 38–50% 属于换手前 10%，说明系统已经在和幻方同一个池子里选股。

**结论**：共性清楚，但不能转化为可交易的增量。九坤的信号本质上是打新或次新；幻方式特征在我们的候选里方向为正、不显著。不采用。可以作为观察：持续记录候选的换手分位和流通市值分位，积累更多样本后再检验。

## 第五十八轮　用前十大流通股东数据拓展：自由流通盘与筹码结构（2026-11-23）

**思路**：我们的候选每段只有约 950 笔独立交易，统计力太弱，所以先在全市场大样本里找规律（2016–21 挑，2022–26 验证），通过后再落到候选和回测，并配随机对照。所有股东信息都从公告次日起才使用。

**新特征**（由前十大流通股东表构建）
- 自由流通比例 = 1 − 持流通 ≥5% 的股东合计占比（即扣掉大股东后的真实流通盘）。
- 自由流通市值、自由流通换手。
- 前十大里的自然人数、机构数（公募、社保、保险、养老、北向、QFII）、前十大集中度。
- 活跃牛散：姓名 ≥3 字、持流通 ≥1%，且公告前已出现在 ≥30 只股票里。受重名干扰太大（仍有 37% 期次命中），只作参考。

**大样本**：全市场非一字涨停（上市满 60 天、非 ST），共 12.45 万个事件。次日开盘买，看次日日内、两日收益；同日去均值，月度聚类 t 检验。门槛：挑选段 |t|≥3，验证段同向且 |t|≥2.5。

| 特征 | 日内 2016–21 / 2022–26 | 两日 2016–21 / 2022–26 |
|---|---|---|
| 自由流通比例 <50% | +0.21%（t3.8）/ +0.18%（t3.3）★ | +0.38%（t4.1）/ +0.37%（t3.5）★ |
| 集中度 >60% | +0.17%（t3.4）/ +0.20%（t3.5）★ | +0.27%（t3.2）/ +0.35%（t3.7）★ |
| 前十大自然人 ≥7 人 | −0.17%（t−4.0）/ −0.11%（t−2.1） | −0.29%（t−3.7）/ −0.22%（t−2.6）★ |
| 自由流通换手前 20% | +0.22%（t3.6）/ +0.35%（t4.5）★ | +0.16%（t1.4）/ +0.34%（t2.9） |
| 无机构 | −0.14%（t−3.3）/ −0.07%（t−1.5） | 不显著 |
| 自由流通市值、总流通市值大小 | 不稳定 | 不稳定 |

- 结论：大股东控盘、真实流通盘小、筹码集中的票，涨停后修复更好；筹码分散在散户手里的更差。
- 尾部：两日亏 ≥10% 的比例，自然人 ≥7 人为 9.0% / 9.9%，无机构为 9.1% / 10.4%，基准为 7.6% / 9.3%。方向一致，但幅度小。

**落到候选**（独立交易，减去同路线均值）：自由流通 <50%、集中度 >60%、自然人 ≥7 人，两段差异都在 ±0.5% 以内，p>0.48，大亏率也无稳定差异。效应 0.2–0.4% 远小于约 0.6% 的抽样误差，在交易层面测不出来。

**回测**（在 v1.6 基础上，相对 v1.5.3 的年化差）

| 方案 | 近期 | 样本外 | 样本外回撤 |
|---|---|---|---|
| Q0 v1.6 | −9.8 | +2.0 | −29.7% |
| **Q1 控盘 ×1.25 / 散户 ×0.8**（敞口大致中性） | **−7.5** | **+3.7** | −28.3% |
| Q3 安慰剂（随机 27% ×1.25、随机 30% ×0.8），4 次 | −26.1 / −26.1 / −22.1 / −12.0 | −0.2 / +6.4 / +2.1 / +1.5 | |
| Q2 散户 ×0.7 | −32.9 | −3.1 | −26.1% |
| Q4 安慰剂（随机 30% ×0.7），3 次 | −33.3 / −48.6 / −39.2 | −4.7 / −3.8 / −5.9 | |

- Q1 相对 v1.6：近期 +2.3、样本外 +1.7，回撤持平或略好。
- 随机对照：近期 Q1 好于全部 4 次安慰剂；样本外好于 4 次中的 3 次。纯靠运气达到这个排名的概率约 8%。再加上大样本的独立证据，算中等强度。
- Q2 只减仓不加仓，比随机略好，但收益损失大，不采用。

**结论**：Q1（控盘 ×1.25、筹码分散 ×0.8）列为 v1.7 候选，证据中等、增量小。上线前需要先接入前十大流通股东的持续更新数据（东方财富个股十大流通股东，每天只需查当天候选，量很小），并先在计划里标注观察。
