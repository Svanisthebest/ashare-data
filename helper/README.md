# A股开单助手（电脑端）

把每天收盘生成的 v1.x 计划变成盘中可执行的提示：9:25 自动算全A竞价红盘率、按规则给出开单单（股数、挂单价），盘中盯高标被砸挂单，14:47 逐只给出卖出建议。

## 安装

**Windows（推荐）**：到仓库 Releases 的「helper」下载 `AshareHelper.exe`，放在任意文件夹，双击运行。会弹出一个黑色窗口（别关）并自动打开浏览器页面 `http://127.0.0.1:8765/`。

**任何装了 Python 3.9+ 的电脑（Windows / Mac / Linux）**：下载 `helper/launcher.py`，运行 `python launcher.py`。

第一次打开后在页面「账户」里填账户总资产。持仓、设置只保存在本机：Windows 在 `%APPDATA%\ashare_helper\`，其他系统在 `~/ashare_helper/`。

## 同步升级

- 启动器每次启动都会从仓库下载最新的 `helper/core.py`（核心程序）；读不到就用上次缓存的版本。
- 规则（路线顺序、仓位、竞价开关、入场 / 卖出参数）来自 `data/helper/rules.json`，由每天的 `v1_plan.py` 生成，和回测、模拟盘同一套参数。
- 所以模型以后升级，只要仓库更新，各台电脑**重新打开助手**就是新版本，不用重装。只有启动器本身改动时才需要重新下载 exe。
- 国内读不到 GitHub 时，在页面「设置」里填镜像地址（例如 `https://ghfast.top/https://raw.githubusercontent.com/Svanisthebest/ashare-data/main`）。

## 每天怎么用

1. 9:20 前打开助手（开着别关）。页面顶部会显示计划日期是否是今天该用的。
2. 9:25:15 后自动生成开单单（也可点「生成开单单」）：红盘率 → 竞价开关 → 每只候选「买入 / 挂单 / 不买」及原因、股数、挂单价。抓不到全市场行情时，可手动填你券商软件里看到的红盘率。
3. 在券商软件下单，成交后点「已成交」，填实际价格和股数，记入持仓。
4. 高标被砸是开盘后挂限价单，页面会提示最低价是否已到挂单价；收盘前没成交就撤单。
5. 14:47 自动做卖出检查：每只持仓「卖出 / 持有 / 推迟」及原因（涨停、止损、总龙头首阴多拿、亏损且中证1000 跌 ≥ 1% 推迟一天、到期）。卖完点「已卖出」；继续持有的点「按建议记录」保存多拿 / 推迟状态。

## 说明

- 行情来自东方财富（全市场）和腾讯（个股、中证1000），都是公开网页接口，偶尔会抓不到；数据有几秒延迟。
- 持有天数按工作日算，节假日未扣。
- 仅供参考，不构成投资建议；规则来自历史回测，下单以券商软件为准。
