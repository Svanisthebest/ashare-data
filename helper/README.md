# A股开单助手（电脑端）

把每天收盘生成的 v1.x 计划变成盘中可执行的提示：9:25 自动算全A竞价红盘率、按规则给出开单单（股数、挂单价），盘中盯高标被砸挂单，14:47 逐只给出卖出建议。

## 安装

**Windows（推荐）**：到仓库 Releases 的「helper」下载 `AshareHelper.exe`，放在任意文件夹，双击运行。会弹出一个黑色窗口（别关）并自动打开浏览器页面 `http://127.0.0.1:8765/`。

**任何装了 Python 3.9+ 的电脑（Windows / Mac / Linux）**：下载 `helper/launcher.py`，运行 `python launcher.py`。

第一次打开后在页面「账户」里填账户总资产。持仓、设置只保存在本机：Windows 在 `%APPDATA%\ashare_helper\`，其他系统在 `~/ashare_helper/`。

## 同步升级

- 启动器每次启动都会从仓库下载最新的 `helper/core.py`（核心程序）；读不到就用上次缓存的版本。
- 规则（路线顺序、仓位、竞价开关、入场 / 卖出参数）来自 `data/helper/rules.json`，由每天的 `v1_plan.py` 生成，和回测、模拟盘同一套参数。
- 所以模型以后升级，只要仓库更新，各台电脑**重新打开助手**就是新版本，不用重装。只有启动器本身改动时才需要重新下载 exe。
- 国内读不到 GitHub 时，在页面「设置」里填镜像地址（例如 `https://ghfast.top/https://raw.githubusercontent.com/Svanisthebest/ashare-data/main`）。

## 每天怎么用

1. 9:20 前打开助手（开着别关）。页面顶部会显示计划日期是否是今天该用的。
2. 9:25:15 后自动生成开单单（也可点「生成开单单」）：红盘率 → 竞价开关 → 每只候选「买入 / 挂单 / 不买」及原因、股数、挂单价。抓不到全市场行情时，可手动填你券商软件里看到的红盘率。
3. 在券商软件下单，成交后点「已成交」，填实际价格和股数，记入持仓。
4. 高标被砸是开盘后挂限价单，页面会提示最低价是否已到挂单价；收盘前没成交就撤单。
5. 14:47 自动做卖出检查：每只持仓「卖出 / 持有 / 推迟」及原因（涨停、止损、总龙头首阴多拿、亏损且中证1000 跌 ≥ 1% 推迟一天、到期）。卖完点「已卖出」；继续持有的点「按建议记录」保存多拿 / 推迟状态。

## 说明

- 行情来自东方财富（全市场）和腾讯（个股、中证1000），都是公开网页接口，偶尔会抓不到；数据有几秒延迟。
- 持有天数按工作日算，节假日未扣。
- 仅供参考，不构成投资建议；规则来自历史回测，下单以券商软件为准。

## 手机推送（v19 起）

开单工具可以把这些消息实时推到手机：9:25 开单单（买什么、挂什么价、多少股）、开单单没生成需要手动处理、10:30 后持仓炸板立即卖、高标被砸挂单可能已成交、14:55 卖出检查（卖哪些、挂什么价）。

在开单工具页面「手机推送」里填下面任意一种，点「保存」，再点「发送测试」确认手机收到：

| 方式 | 手机上在哪看 | 怎么拿到要填的内容 | 免费额度 |
| --- | --- | --- | --- |
| PushPlus（推荐） | 微信 | 微信关注「pushplus 推送加」公众号 → 菜单里拿到 token（32 位字母数字） | 每天 200 条 |
| Bark | iPhone 通知 | App Store 装 Bark → 复制 App 里的地址（https://api.day.app/xxxx） | 不限 |
| 企业微信群机器人 | 企业微信（可同步到微信） | 企业微信建群 → 添加群机器人 → 复制 Webhook 地址 | 不限 |
| 钉钉群机器人 | 钉钉 | 钉钉群 → 智能群助手 → 添加自定义机器人，安全设置选「自定义关键词」填 A股 → 复制 Webhook 地址 | 不限 |
| 飞书群机器人 | 飞书 | 飞书群 → 设置 → 群机器人 → 自定义机器人 → 复制 Webhook 地址 | 不限 |
| Server酱 | 微信 | sct.ftqq.com 微信登录 → 复制 SendKey（SCT 开头） | 每天 5 条，不够用 |

推送设置只存在本机。推送内容（股票名称、价格、股数）会经过对应推送服务的服务器。

## 电脑不开机也能运行（v20 起）

### 方案一：云服务器（主力，功能和电脑上完全一样）

1. 买一台国内云服务器：腾讯云「轻量应用服务器」或阿里云「轻量应用服务器」都行。地域选上海、广州或北京；系统选 Ubuntu 22.04；最低配置（1–2 核、1–2G 内存）就够。价格以官网为准，新用户常有年付活动。
2. 在云服务器控制台的「防火墙」（阿里云叫「安全组」）里添加规则：协议 TCP，端口 8765，来源全部。
3. 在控制台点「登录」（网页终端），粘贴下面一行，把 `你的密码` 换成你自己设的访问密码（至少 6 位，只用字母、数字和 _ @ # % + = . - 这些符号），回车：

   ```
   curl -fsSL https://ghfast.top/https://raw.githubusercontent.com/Svanisthebest/ashare-data/main/helper/install_server.sh | sudo bash -s -- '你的密码'
   ```

   看到「✅ 安装完成」就好了。它会显示一个网址 `http://服务器IP:8765/`。
4. 手机或电脑浏览器打开这个网址，用户名随便填，密码填刚才设的。之后的用法和电脑上一样：填账户资金、点「已成交」、改持仓、设置手机推送。
5. 把电脑上的持仓搬过去：电脑上的开单工具 → 「设置与日志」→「导出数据」，全选复制；在云服务器的页面同一位置粘贴，点「导入」。
6. 搬好以后，电脑上的开单工具就不用开了。如果两边都开、都设了推送，同一条消息会收到两次。

服务器上的开单工具开机自动启动、出错自动重启，每个交易日 8:40 自动重启一次，顺便更新到最新版本。查看运行日志：在网页终端输入 `journalctl -u ashare-helper -n 50 --no-pager`。

注意：网页走的是普通 http，密码请用只在这里用的、足够长的密码。

### 方案二：GitHub 云端提醒（免费备份）

每个交易日 9:06 左右，由「竞价采集保障」定时任务在 GitHub 上启动，运行到收盘。它会推送 9:25 开单单、炸板提醒、挂单可能成交、14:55 卖出检查，标题都带「云端备份·」。

- 它不知道你的真实持仓，按**模拟盘的持仓**推送，股数按 `CLOUD_EQUITY`（默认 100 万）估算。
- 需要在 GitHub 仓库的 Settings → Secrets and variables → Actions 里加一个 Secret：名称 `PUSH_DEST`，值填推送 token 或地址（和开单工具里填的一样）。
- 可选的 Variables：`CLOUD_EQUITY` 填你的账户金额；`CLOUD_ALERT` 填 `off` 可以关掉云端提醒。
- 自检：在 GitHub 的 Actions → cloud_alert → Run workflow，selftest 填 1。手机收到「云端提醒自检」就说明推送通了。
